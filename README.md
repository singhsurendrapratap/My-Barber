# 💈 My Barber - Live Queue & Shop Discovery Prototype

A lightweight, zero-friction web prototype designed to reduce barbershop weekend wait times. 

## Features
- **Zero-Friction Customer Experience:** No account creation required. Search by map, check live queue status (🟢 Low Wait, 🟡 Moderate, 🔴 Busy), and join the virtual line.
- **Custom Arrival Reminders:** Enter how many minutes you take to travel, and the app alerts you when it's time to head out based on the shop's pace.
- **Shop Owner Dashboard:** Split-screen layout featuring an active chair focus (*Next*, *Hold*, *Closing Soon*) and a live scrollable waiting line.

## Built With
- **Frontend/App Framework:** Streamlit
- **Interactive Maps:** Folium + Streamlit-Folium
- **Hosting:** Streamlit Community Cloud + GitHub
